ROOT CAUSE ANALYSIS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PRIMARY CAUSE: Database connection pool exhaustion on DB-PROD-03 caused by an
unoptimized query introduced in deployment v2.8.1 (deployed May 15, 2025 at 18:30 UTC).
The query performed a full table scan on the payroll_transactions table (12.4M rows)
without utilizing the existing index, consuming all available connections within 4 minutes.

CONTRIBUTING FACTORS:
1. Deployment v2.8.1 was not tested against production-scale data volume
2. Connection pool monitoring threshold was set too high (95% vs recommended 80%)
3. Authentication service lacked circuit breaker for database dependency failures
4. On-call engineer required 2 minutes to acknowledge alert (SLA: 1 minute)
